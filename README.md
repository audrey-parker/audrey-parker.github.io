# Audrey Parker — personal website

A static personal and research website built for GitHub Pages.

## Preview locally

From this folder, run:

```bash
python3 -m http.server 8080
```

Then open `http://localhost:8080`.

## Publish with GitHub Pages

Create a public repository named `audrey-parker.github.io`, add these files to the repository root, and push to the `main` branch. In the repository settings, choose **Pages**, then deploy from the `main` branch and `/ (root)` folder.

## Before publishing

- Add an approved headshot if desired.
- Decide whether to make a downloadable CV public.
- Confirm publication and media links.
- Update the introductory copy with any personal perspective you want to share.
